صفحه‌ها از دادهٔ پروژهٔ مجاز استفاده می‌کنند. کاربر محدود به Project تنها ردیف حساب خودش را در فهرست اعضا دریافت می‌کند. منابع مشترک از پروژه‌های مجاز دیده می‌شوند و روابط و شناسه‌های غیرمجاز از پاسخ حذف می‌شوند. بررسی مجوز در Repository یا API انجام می‌شود. مقدار Vault در قرارداد داده وجود ندارد.

هر حساب یک عضویت فعال دارد. دعوت فعلی می‌تواند مجوز کل Workspace یا فهرست پروژه بدهد. رابط دعوت، انتخاب صریح پروژه را پیش‌فرض می‌گیرد. Snapshot نوشتنی برای سازگاری لوکال است و وقتی MFA اجباری است بسته می‌شود. Related record permissions also apply to document histories, monitoring observations and assistant retrieval.
