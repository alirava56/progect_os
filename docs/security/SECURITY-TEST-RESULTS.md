# نتایج آزمون امنیت

حساب‌ها، داده‌ها و کلیدها در طول اجرا ساختگی بودند. درخواست‌های HTTP به سرور و دیتابیس موقت loopback رفتند. اسکن وابستگی‌ها در رجیستری npm در ۱۹ نوامبر ۲۰۲۶ صفر مورد گزارش کرد. محدودهٔ اسکن، Commit و کدهای خروج در [گزارش تحویل](../verification/FINAL-DELIVERY-REPORT-FA.md) ثبت شده‌اند.

| کنترل | آزمون و دامنه |
|---|---|
| Origin و نشست | درخواست بدون نشست و Origin خارجی رد شدند. Cookie تولید HttpOnly/Secure و نشست‌ها دارای انقضای مطلق و بی‌فعالیتی‌اند. |
| RBAC و IDOR | Getterهای Scope، Snapshot، Record، History و Assistant روی نقش محدود آزموده شدند. درخواست نوشتن رکورد پروژهٔ غیرمجاز رد شد. تغییر Grant برای نشست فعال دوباره بررسی شد. |
| قیدهای مالکیت | Editor زیرساخت یا تنظیمات را تغییر نداد. Viewer نتوانست دعوت یا رکورد ایجاد کند. Vault در Snapshot، API رکورد و صفحه برای غیرمالک بازگردانده نشد. |
| MFA | ثبت نیازمند رمز است. تأیید از نشست دیگر شکست خورد. TOTP Replay، Recovery تک‌مصرف و ابطال نشست پیشین آزموده شدند. |
| ورودی | سقف جریان JSON، اعتبارسنجی تاریخ، چرخهٔ روابط، مقادیر مالی و دادهٔ مشکوک بررسی شدند. آزمایش‌های Secret از متن ساختگی استفاده کردند. |
| HTTP روی PostgreSQL | API آماده‌بودن، ساخت Owner، Cookie، نوشتن و خواندن رکورد و رد مهمان در Build تولید آزموده شدند. |
| CSP | هدر nonce صفحهٔ ورود در Build تولید بررسی شد. فرم واقعی ایجاد پروژه فقط پس از Commit به صفحهٔ آن رفت. |
| بیرونی | Probe خصوصی در DNS Mock پیش از اتصال متوقف شد. Vault و GitHub Mock، بررسی امضا و گزیدهٔ استناد دقیق آزموده شدند. |

ممیزی مستقل امنیت محیط هدف، تحلیل CodeQL میزبانی‌شده، SAST جامع و دسترسی نقش‌های واقعی PostgreSQL در انتظار تأییدند. نتیجهٔ آزمون‌های محلی پیش‌شرط بررسی انتشار است.
