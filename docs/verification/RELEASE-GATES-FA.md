# Gateهای انتشار ProjectOS

Gate وقتی PASS است که پیاده‌سازی، آزمون مسیر عادی و خطا، شواهد عملیاتی و محیط مربوط تأیید شوند. نتیجهٔ محلی به‌تنهایی مجوز انتشار عمومی ایجاد نمی‌کند.

| Gate | تأیید موجود | شرط تکمیل |
|---|---|---|
| A | نصب تمیز، Build، TypeScript، ESLint، Core، CI ویندوز و لینوکس و CodeQL، Smoke ایزوله و ۱۳ آزمون Workflow روی دادهٔ آزمایشی با ورود واقعی. جریان Backup و گردش‌های کاری در CI تأیید شدند. | نتیجهٔ اجرای نهایی روی هر سه مرورگر در گزارش تحویل ثبت می‌شود. |
| B | PostgreSQL واقعی، Migration و Rollback در تراکنش، HTTP RBAC/MFA، عملیات اتمیک و بازیابی محلی | مدل هدف کامل، بررسی نقش‌های محیط هدف، Cutover و Rollback عملیاتی |
| C | Vault فراداده، تکرار و Lease پایدار، Backup رمزنگاری‌شده، بررسی آفلاین و Restore محلی | Vault و ارسال آزمایشی واقعی، Timer عملیاتی، Offsite و RPO/RTO |
| D | مشاهدهٔ HTTPS و عامل میزبان دارای زمان و منبع، GitHub و Memory مجوزمحور، فاکتور و اقساط و پرداخت با واحد جزء و نرخ تبدیل دستی دارای منبع و زمان | تأیید ارائه‌دهنده، Backfill خودکار GitHub، دریافت خودکار نرخ، تطبیق پرداخت با قرارداد، VPN/SLO و جست‌وجوی معنایی |
| E | شواهد HTTP، A11y خودکار محدود، ۲۱ مسیر RTL در شش عرض، ۱۳ Workflow محلی، Migration و بازیابی ایزوله | بررسی جامع بصری و دستی WCAG، load/soak و ممیزی مستقل |

نتیجهٔ رسمی، سیاست ممنوعیت Production، دستورات اجرا و شواهد در [گزارش تحویل](FINAL-DELIVERY-REPORT-FA.md) درج شده است.
