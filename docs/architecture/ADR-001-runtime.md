# ADR-001 — انتخاب SQLite برای بوت‌استرپ محلی (سند تاریخی)

**وضعیت: Superseded as a release decision؛ تصمیم فعلی برای انتشار هنوز تأیید نشده است.**

این تصمیم در نسخه اول Private Preview به‌دلیل فراهم‌نبودن PostgreSQL، Prisma و دسترسی npm گرفته شد. SQLite برای توسعه محلی با نشست سروری و تراکنش‌ها به‌کار رفت. از آن زمان دعوت تیم با نقش محدود، TOTP و چند API رکوردی اضافه شده‌اند؛ بنابراین توصیف قدیمی «فقط یک مالک / بدون MFA» دیگر وضعیت فعلی نیست.

- **واقعیت Runtime کنونی:** SQLite محلی با مدل Workspace و عضویت محدود، نسخه‌بندی و ذخیره‌سازی رکوردی اولیه.
- **هدف نهایی تأییدنشده:** PostgreSQL، مهاجرت و Rollback تست‌شده، کنترل مجوز کامل هر Workspace/Project و عملیات چندکاربره مطمئن.
- **مرز امنیتی:** صرفاً محیط خصوصی آزمایشگاهی؛ هیچ Secret واقعی و هیچ انتشار عمومی تا بسته‌شدن Gateها.
- **مراجع معتبر وضعیت کنونی:** `docs/verification/STATUS.md`، `docs/verification/RELEASE-GATES-FA.md` و `docs/security/THREAT-MODEL.md`.
